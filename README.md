# Trip Advisor - Recherche de Lieux sur Carte

Le projet Trip Advisor est une application web développée avec React qui permet aux utilisateurs de rechercher facilement des restaurants, hôtels et attractions à proximité grâce à une carte interactive basée sur Google Maps. L’application récupère des données via une API externe et affiche pour chaque lieu une fiche détaillée avec ses informations principales.

## Fonctionnalités

### Recherche et Localisation

- **Localisation de l’utilisateur** : Détecte automatiquement la position actuelle pour afficher les lieux proches.
- **Recherche par catégorie** : Permet de filtrer entre restaurants, hôtels ou attractions.
- **Filtrage par note** : Affiche uniquement les lieux dépassant un certain nombre d’étoiles.
- **Recherche dynamique** : Les résultats se mettent à jour en fonction des déplacements sur la carte.

### Affichage des Lieux

- **Carte interactive Google Maps** : Marqueurs affichés en temps réel selon la zone visible.
- **Fiches détaillées** : Affiche les informations principales de chaque lieu (nom, note, adresse, type).
- **Liste des lieux** : Présentation sous forme de cartes claires et lisibles, synchronisées avec la carte.

## Technologies Utilisées

- **React** : Framework principal pour la construction de l’interface.
- **Google Maps JavaScript API** : Affichage de la carte et gestion des marqueurs.
- **Tailwind CSS** : Stylisation rapide et responsive.
